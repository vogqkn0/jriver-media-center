## 谁适合买，谁买了会后悔

JRiver 的核心是媒体库管理和播放引擎，不是“能播就行”。想清楚这一点，选择就简单了。

适合买的人有这么几类。硬盘里躺着几百 GB 到几 TB 本地音乐，并且认真整理过标签的，JRiver 的智能播放列表可以按评分、流派、年代设定条件实时生成列表，这类玩法在免费播放器里要么没有，要么得自己装插件凑。用独立 DAC 或者一套音响听歌的也值，有中文评测把它称作发烧友圈子里的音质标杆，不少音响厂商会直接把它列为自家设备的推荐播放软件。把电脑接到客厅电视当 HTPC 的同样合适，剧院模式配遥控器，蓝光原盘和 MKV 这类文件靠 Red October 的解码链路就能放，不用另外折腾解码包。还有一类需求是其他播放器不提供的：多房间播放、DLNA 网络共享、电视录制。

该劝退的也说清楚。主要听流媒体的人别买，JRiver 能播 Netflix 和 YouTube，但它的主场是本地文件，推荐算法和跨设备无缝续播这些它给不了你。想装完就能用的人也别买，设置项多，界面是传统桌面软件的思路，第一次打开要花时间建库、指定音频输出设备。英文评测站 itechguides 在评测里给的一条缺点就是功能集对基础播放需求明显过剩，这话不假。只想要个免费播放器的人更不用考虑，foobar2000 和 VLC 都能播，JRiver 卖的从来不是“能播”这个能力。

## 激活、换电脑、跨版本升级的规矩

付款之后你会收到一个 30 位字符的注册码（Registration Code），装机时用它生成安装密钥（Install Key）。这两个东西不是一回事，注册码要长期保存，安装密钥是一次性的。

官方规则是每 12 个月可以生成 10 次 Install Key，每个 Install Key 有效两周。换电脑、重装系统、在虚拟机里试装，都会消耗次数。店铺页面写的“最多 10 台设备”说的是同时激活的设备数量，和这个年度生成次数不是一个概念。正常家庭用法碰不到上限，但你要是习惯频繁重装系统，可能会先撞上 Install Key 的次数限制。

注册码丢了有救。官方有个 Restore 页面，用购买时填的邮箱和密码就能找回，每年 10 次免费恢复，不限年数。所以购买邮件别删，最好把注册码另存一份到密码管理器或者网盘。

跨大版本不通用。MC35 的注册码激活不了 MC36，要升级就得买升级授权。这也是为什么前面说“这个版本你打算用几年”比“多少钱”更值得先想。

## 常见问题

**买了 MC35，以后出新版本还要再花钱吗？**
要。授权只覆盖一个大版本，MC35 能用到它最后一个小版本更新。想升到下一个大版本，得买升级授权，价格比新购低不少，具体金额看当时的购买页。

**一个授权能装几台电脑？**
店铺页面写的是最多 10 台设备，同版本授权只能在对应系统上用。Master 版可以在 Windows、macOS、Linux 之间任意分配这 10 台。

**Mac 和 Linux 能用吗？**
Mac 有单独的单平台版。Linux 只能靠 Master 版覆盖，官方另有 79.98 美元的 Linux 单平台授权，店铺是否上架以页面为准。

**在数码荔枝买的授权和官网买的有区别吗？**
店铺是第三方授权经销商，激活走的是官方那套注册码加 Install Key 的机制，售后找店铺。至于授权是否全球通用、换地区使用有没有限制，页面没有写明，下单前建议直接问客服确认，这个我给不了确定答案。

**能退款吗？**
退款条款以下单页面的说明为准，页面没写清楚的部分，建议当成激活后不可退来处理。所以才把 30 天试用放在第一步，先用够再付钱。
